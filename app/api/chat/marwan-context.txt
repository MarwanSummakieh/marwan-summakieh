MARWANOS (Godot 4, GDScript, bootc, Fedora / Universal Blue, systemd, gamescope, Plymouth, Bash, GitHub Actions) — In production
A Fedora-based, image-mode Linux distribution built on bootc that cold-boots straight into a controller-navigable gaming shell written in Godot 4. No desktop, no login screen, no visible text. The OS is a container image; upgrades ship via `bootc upgrade` with `bootc rollback` as undo. Includes a silent boot pipeline (custom Plymouth theme, hidden GRUB), a fleet of systemd units (app scan/launch, flatpak installs, flight recorder, boot-success watchdog, USB automount, display profiles), a dev-mode flag that enables sshd/terminal, and 12 architecture decision records. Phase 1 adds a Rust library daemon talking to the shell over JSON-RPC/WebSocket. The MarwanOS name is also Marwan's personal brand (the graffiti logo on the site). Dossier: /devlog/marwanos
GitHub: https://github.com/MarwanSummakieh/MarwanOS

SIMULATED PROSTHETIC VISION — MSc THESIS (Python, NumPy, OpenCV, PyTorch, RGB-D, RANSAC) — Research
Master's thesis "Real-Time Depth-Based Walkable-Space Encoding for Simulated Prosthetic Vision in Indoor Navigation". A Python pipeline: RGB-D source → RANSAC floor + height-rule walkable-space detection → encoder (raw vs. simplified hazard-aware) → phosphene renderer with jitter/dropout/afterglow → latency metrics. Includes TinySegNet, a ~70K-parameter depthwise-separable U-Net trained on procedurally generated corridors, an evaluation CLI (IoU + latency), NYU Depth V2 support and a pytest suite. This is the platform for a human study. Dossier: /devlog/prosthetic-vision
GitHub: https://github.com/MarwanSummakieh/real-time-video-feed-subsampling
